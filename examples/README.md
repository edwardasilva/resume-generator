# Examples

This folder holds five made-up example resumes and one made-up two-page CV, each as a JSON source and the PDF built from it. `alex-doe-resume.png` is a picture of `Alex-Doe-Resume.pdf`, shown in the main README.

| Example    | Source                             | PDF                                                              | Description                                                                                                                                                                                                                  |
| ---------- | ---------------------------------- | ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Alex       | [alex.json](alex.json)             | [Alex-Doe-Resume.pdf](Alex-Doe-Resume.pdf)                       | Alex Doe, an electrical engineering student expected to graduate in May 2027, with two projects and a sales job with two bullets. The school, GPA, and measured figures are placeholders, with `[X]` marking a number to measure. |
| First year | [first-year.json](first-year.json) | [Alex-Doe-Resume-first-year.pdf](Alex-Doe-Resume-first-year.pdf) | Alex Doe as a first-year electrical engineering student expected to graduate in May 2030, with one class project and a grocery job with two bullets.                                                                              |
| Sophomore  | [sophomore.json](sophomore.json)   | [Alex-Doe-Resume-sophomore.pdf](Alex-Doe-Resume-sophomore.pdf)   | Alex Doe as a second-year electrical engineering student expected to graduate in May 2029, with two projects, an electrical lead role in a robotics club, and a barista job with two bullets, because the page has room. |
| New grad   | [new-grad.json](new-grad.json)     | [Alex-Doe-Resume-new-grad.pdf](Alex-Doe-Resume-new-grad.pdf)     | Alex Doe as a new graduate (May 2026) with two engineering internships, two projects, and certifications. Experience comes right after Education, and the resume uses the Times font.                                                     |
| Packed     | [packed.json](packed.json)         | [Alex-Doe-Resume-packed.pdf](Alex-Doe-Resume-packed.pdf)         | Alex Doe as a graduating student (May 2026) with three engineering roles, a tutor job on one line because the page is full, three projects, and long skill lists, using the Arial font. |
| CV         | [alex-cv.json](alex-cv.json)       | [Alex-Doe-CV.pdf](Alex-Doe-CV.pdf)                               | Alex Doe's two-page CV, set with `"document": "cv"`. It adds honors, scholarships, four jobs with bullets, four projects, certifications, activities, and organizations, with section titles and labels set in the JSON.      |

To rebuild a PDF, from the repository root run `./run examples/alex.json`. The PDF is written next to the JSON file. The same command works for the other five files.
